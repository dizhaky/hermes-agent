# Checkpoint record — copy-paste skeleton

Search the store for an existing record with this task's marker before writing.
Update in place if found; never create a duplicate.

```
CHECKPOINT: <task name / stable marker>

GOAL:
<the durable objective, 1–2 sentences>

DONE:
- <completed step, with enough detail to trust without re-checking>
- ...

IN-FLIGHT:
<the single step underway + which substep>

NEXT-3:
1. <next concrete action>
2. <...>
3. <...>

BLOCKERS:
- <what's stuck and on whom/what> (or "none")

KEY-FACTS:
- <IDs, paths, URLs, decisions, constraints the next session needs>

ARTIFACTS:
- <file/PR/doc> — <location>

RESUME:
<the literal first command or prompt to run on resume>

UPDATED: <YYYY-MM-DD HH:MM local, labeled — e.g. "2:15 PM EDT">
```
