  `.mcp.json` next to `.env`, and an MCP `env` block can hold API keys in a repo
  that ships 1Password and Bitwarden credential bootstrapping. Unignoring it to
  fix a path would trade a cosmetic problem for a real one. `.env.example` and
  `cli-config.yaml.example` are the repo's existing pattern for exactly this, so
  this follows it.
- **Why the two repos differ:** crm-pipeline does *not* gitignore `.mcp.json`, so
  there the declaration simply moved into a tracked `.mcp.json`. Here it can't be
  tracked, so the tracked artifact is the template. Both repos end up with no
  machine-specific path in version control.
- **Requires one manual step per machine:** `cp .mcp.json.example .mcp.json`.
  Until that runs, `codebase-memory` is unavailable — including on the Mac, where
  it previously worked via the hardcoded path. This is a deliberate trade: a
  one-time copy in exchange for tracked config that isn't wrong for every machine
  but one.
